# Foldria v0.1.0 — Windows (x64)

Erster Windows-Release des lokalen Datei-Sortierers **Foldria**.

**Downloads**

- `Foldria-Setup-0.1.0-x64.exe` — Windows-Installer, Installationsordner auswählbar.
- `Foldria-Portable-0.1.0-x64.exe` — portable EXE ohne Installation.
- `SHA256SUMS.txt` — Prüfsummen der EXE-Dateien.

**Features:** Individuelle Dateityp-Regeln, wählbarer Quell-/Zielordner, Vorschau vor dem Sortieren, Schutz vor dem Überschreiben, Duplikat-Erkennung per SHA-256, manuelle Papierkorb-Aktion und Rückgängig-Funktion.

**System:** Windows 10/11, 64-Bit. Die Dateien sind nicht digital signiert; Windows SmartScreen kann deshalb eine Warnung anzeigen. Bitte die Dateien und den Herausgeber selbst prüfen.

**Hinweis:** Der erste Release ist eine Vorabversion. Vor dem Sortieren wichtiger Daten bitte ein Backup machen.
